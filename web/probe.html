Razer HID probe

Step 1 of the Razer web app: see what Chrome can reach, and whether the Viper V3 Pro and BlackShark V2 Pro answer.

1. Connect

Quit Razer Synapse completely (tray icon too). Click Add Razer device once per device: the mouse on its cable, the mouse through its dongle, and the headset dongle. Chrome remembers them after that.

2. Mouse reads

Read-only commands from the documented Razer mouse protocol. Green in the log means the mouse answered.

3. Profile experiments

Onboard profiles aren't documented. If the values below change with the storage slot, the slot byte is the profile number. These only read.

4. Headset & raw tools

The headset uses an unknown protocol. Pick it as the target and read its feature reports. With “Open all & listen” on, change volume or the EQ preset, or plug in the charger, and watch for input reports.
